Quick Start & 3-Step Rapid Workflow

KyteRename is engineered to deliver the smoothest, most intuitive renaming experience on Windows. Process tens of thousands of files in just three simple steps:

Step 1

Drag in Files or Folders

Select files or entire directories directly from File Explorer and drop them into KyteRename; or right-click in Windows and choose "Batch Rename with KyteRename".

Step 2

Configure Rules with Live Preview

Combine replacements, prefixes, suffixes, numbering, or EXIF tags in the right-hand panel. The left pane highlights matches in Amber Gold while the right pane renders results in under 50ms.

Step 3

Execute Rename Safely

Press Enter or click "Execute Batch Rename". The DAG topological engine safely commits the operation and automatically creates an atomic undo snapshot.

Command-Line Interface (CLI) Support: Launch directly with target directory paths, e.g.: python main.py "D:\Photos\2026" to import all items automatically.

Target Scope & Precision Modification Control

To prevent accidental changes to file extensions that could break format associations, KyteRename offers strict "Target Scope" options for every rule:

Base Name Only
Default Safe Mode

Affects only the filename preceding the extension dot. Extensions are strictly protected from accidental regex or replace operations.

Extension Only
Extension Dedicated

Affects only the extension following the dot. Ideal for converting uppercase camera .JPG to lowercase .jpg, or correcting mismatched extensions.

Full Filename
Advanced Custom

Processes the base name and extension together as a single unified string. Perfect for advanced regex re-structuring across the entire filename.

Smart Serial Numbering Rules

Sequential numbering is fundamental for organizing documents, photo albums, and contracts. KyteRename's numbering engine provides maximum flexibility:

Flexible Parameters
  • • Start Index: Start from 1, 0, or any arbitrary integer (e.g. 101).
  • • Step Increment: Specify increments (+1, +2, or custom steps).
  • • Zero-Padding: Set to 3 digits to produce 001, 002; 4 digits for 0001.
Placement Configuration
  • • Prefix: e.g. 001_Photo.jpg
  • • Suffix: e.g. Photo_001.jpg
  • • Replace Entire Name: Replace the base name entirely with serial numbers.

3-Stage DAG Safe Topological Renaming Technology

This is KyteRename's industry-leading core innovation. When batch renames encounter complex dependency chains or deadlocks, traditional renamers often cause catastrophic file overwriting and permanent data loss:

// Classic cyclic dependency: Swapping A to B, and B to A
If executed in sequential order by traditional tools:
Step 1: A.txt ➔ B.txt (Original B.txt is overwritten and deleted! Total disaster!)
// KyteRename DAG topological cycle-breaking execution:
Stage 1: Analyze directed graph topological cycles and detect dependency conflict.
Stage 2: Temporarily rename A.txt with microsecond token __kyte_tmp_12345.tmp
Stage 3: Safely execute B.txt ➔ A.txt
Stage 4: Atomically commit the temporary token to B.txt (Perfect zero-loss swap!)
NTFS Case-Insensitive Two-Phase Transition

Windows does not distinguish casing. Changing file.txt to FILE.TXT automatically employs two-phase commits to prevent "File already exists" system errors.

Windows MAX_PATH Extended Path Protection

Automatically attaches Windows \\?\ extended path prefixes, breaking the classic 260-character limit for rock-solid nested directory renaming.

Ctrl+Z Snapshot Atomic Undo System

Even if you apply an incorrect rule by mistake, KyteRename provides an ironclad fail-safe mechanism:

Three Pillars of the Snapshot Architecture:

  • • Instant Millisecond Rollback: Press Ctrl+Z anytime to roll back immediately along the exact reverse path.
  • • Cross-Session Persistent Logs: Snapshots are preserved locally in JSON format. Even if you restart your PC, you can invoke the History Dialog to roll back past executions.
  • • Reverse Topological Guarantee: Undo runs strictly adhere to reverse DAG topological orders, guaranteeing zero collision or overwrite during the rollback process.
