01

快速開始與 3 步極速工作流

KyteRename 旨在提供 Windows 上最直覺流暢的批次更名體驗。只需 3 個步驟，即可安全處理數萬個檔案：

Step 1

拖入檔案或資料夾

從檔案總管直接選取檔案或整個目錄，拖曳進 KyteRename 視窗；亦可在 Windows 右鍵選單點擊「使用 KyteRename 批次整理」。

Step 2

設定規則與即時預覽

在右側規則面板自由組合取代、前後綴、流水號或 EXIF 標籤；左欄會以琥珀金高亮匹配處，右欄即刻顯示 50ms 零延遲新檔名。

Step 3

一鍵安全執行更名

按下鍵盤 Enter 或點擊「執行更名」，DAG 拓撲引擎瞬間安全提交，自動建立原子快照備查。

命令列支援 (CLI)：您可以透過命令列快速傳入路徑啟動，例如：python main.py "D:\Photos\2026"，程式會自動將該目錄所有項目匯入。

雙欄即時對照與琥珀金高亮匹配

傳統批次更名工具最常讓人不安的就是「不知道改完後長怎樣」或是「盲猜取代字串是否符合預期」。KyteRename 獨家設計了高對比雙欄預覽系統：

琥珀金動態匹配標記 (Regex Delegate)

當您在搜尋框輸入文字或正則表達式時，KyteRename 會在左欄原始檔名中，將被比對命中的文字片段以琥珀金背景（Amber Gold）即時標亮：

原始檔名範例：DSC_20261005_001.JPG

您能瞬間確認哪些部分會被替換、哪些部分會被保留，在正式執行前就擁有一目了然的確定感。

Qt 虛擬滾動 (Virtual Scroll) 技術

底層基於 QAbstractTableModel 開發。即便載入 10,000+ 筆檔案，程式也只渲染畫面可見的十幾行，垂直滾輪共用同步，拖曳絲滑順暢，50ms 內完成全量規則預覽重算。

03

作用域與精確修改控制 (Target Scope)

為了防止使用者意外改到副檔名導致檔案格式損毀，KyteRename 為所有規則提供了嚴謹的「作用域（Scope）」選項：

僅主檔名 (Base Only)
預設安全模式

僅對副檔名前的檔名主體生效。副檔名受絕對保護，絕不因正則或替換意外損壞關聯。

僅副檔名 (Ext Only)
副檔名專用

僅對點號後的副檔名生效。適合統一將相機的 .JPG 改為 .jpg，或修正錯誤格式副檔名。

完整檔名 (Full Name)
高階自訂

包含主檔名與副檔名整串進行處理。適用於高階正則重新組合完整檔案名稱。

05

智慧補零流水號規則 (Serial Numbering)

依序編號是整理文件、相簿與合約最核心的需求。KyteRename 的流水號引擎具備高度靈活性：

彈性參數控制
  • • 起始序號 (Start)：自訂從 1、0 或任意數字開始（如 101）。
  • • 步進值 (Step)：支援遞增步長（+1、+2 或跳號）。
  • • 補零位數 (Padding)：設定為 3 碼即自動補零為 001, 002；4 碼為 0001。
插入位置配置
  • • 開頭 (Prefix)：例如 001_相片.jpg
  • • 結尾 (Suffix)：例如 相片_001.jpg
  • • 全名覆蓋 (Replace)：直接將主檔名改為流水號。

08

安全三階段 DAG 拓撲換名技術

這是 KyteRename 領先業界的核心技術。當批次改名遇到複雜的依賴鏈或死鎖循環時，傳統軟體常會發生「檔案相互覆蓋而永久遺失」的悲劇：

// 經典循環依賴案例：A 換成 B，B 換成 A
若按普通順序直接改名：
Step 1: A.txt ➔ B.txt (原本的 B.txt 被覆蓋刪除！嚴重災難！)
// KyteRename DAG 拓撲破圈演算法執行過程：
階段 1：分析有向圖拓撲環，偵測到循環衝突。
階段 2：將 A.txt 暫存更名為微秒級暫存標記 __kyte_tmp_12345.tmp
階段 3：安全執行 B.txt ➔ A.txt
階段 4：將暫存標記原子提交為 B.txt（兩者完美對調，零損耗）
NTFS 大小寫不敏感兩階段過渡

Windows 不區分檔名大小寫，將 file.txt 改為 FILE.TXT 時，系統自動採用兩階段提交，避免 Windows 回傳「檔名已存在」的錯誤。

Windows 超長路徑 (MAX_PATH) 防護

底層自動掛載 Windows \\?\ 擴展路徑前綴，打破傳統 260 字元限制，深層多層資料夾依然穩如泰山。

就算手滑按錯了更名規則，KyteRename 也為您準備了萬無一失的救悔機制：

快照安全體系三大特點：

  • • 毫秒級即時還原：在視窗隨時按 Ctrl+Z，系統即刻原路還原。
  • • 跨工作階段持久記錄：快照以 JSON 日誌格式儲存於本地。即使關閉程式、重新開機，也能透過「歷程對話框」指定回滾過去的任一次改名。

Q: 執行更名時提示「檔案被佔用」或「拒絕存取」？

A: 通常是因為該檔案目前正在被微軟 Excel、Word、播放器或其他程式開啟並鎖定中。請先將佔用該檔案的程式關閉，然後點擊「重試」；您也可以選擇「略過鎖定檔案」，系統會繼續完成其餘檔案的更名。

Q: 如何更換深色模式 (Dark Mode)？

A: 點擊視窗右上角或功能表的「設定 (Settings)」➔「外觀模式 (Appearance Mode)」，可選擇「跟隨系統 (System)」、「深色模式 (Dark)」或「淺色模式 (Light)」，介面會即時無縫切換。

Q: 購買正式版後享有什麼維護與更新保障？

A: 本商品為一次性買斷，享有一年內免費維護與 Bug 修復。若未來作業系統大型改版（如 Windows 升級）導致軟體需重構，新版本將另行販售。
